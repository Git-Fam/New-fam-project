■ ファイル構成

- index.html
  公開画面。LP / スワイプ / 分析演出 / 診断結果 / 求人導線。

- line-complete.html
  LINE連携完了後の戻り先画面。

- terms.html / privacy.html
  利用規約 / プライバシーポリシー。仮置き事項はHTML上部にコメントあり。

- admin/index.html
  管理画面ログイン用の静的HTML。ログイン前は管理画面本体を含まない。

- config.js
  公開画面用の接続設定。管理用Secretは置かない。

- admin/config.js
  管理画面用の接続設定。管理用Secretは置かない。

- css/reset.css / css/styles.css
  リセットCSS / 画面デザインCSS。HTML/CSSは今後変更予定。

- src/app.js
  公開側JS。スワイプ、診断ロジック、Supabase保存、LINE導線、GAイベント送信。

- src/admin.js
  管理画面本体JS。マスタ保存、画像アップロード、画像軽量化、KPI取得。

- src/admin-login.js
  管理画面ログイン専用JS。ログイン成功後にadmin-uiから管理画面HTMLを取得。

- src/data.js
  初期マスタ。40問カード、診断軸、15タイプ診断結果。

- supabase/functions/*
  Supabase Edge Functions本体。

- supabase/dashboard/*-index.ts
  Supabase DashboardのEdge Functions Codeタブへ貼る用の単体ファイル。

- supabase/migrations/*.sql
  DB定義、KPI集計、自動削除Cronの控え。


■ 注意

- JSで使用しているid/class名は変更すると機能が壊れる可能性あり。
- JS使用中のid/class名はHTML内にコメントあり。
- 管理画面はログイン画面あり。ログイン前のHTMLには管理画面本体を入れない。
- 管理画面本体HTMLはadmin-ui Edge Functionからログイン後に取得する。
- 管理パスワードはSupabase SecretsのADMIN_LOGIN_PASSWORDにだけ保存する。
- セッション署名用SecretはADMIN_SESSION_SECRET。
- ログイン失敗は15分以内5回まで。超過時は15分ブロック。
- 管理画面はnoindex設定済み。
- 公開診断でユーザーに表示する質問・画像・結果文は完全な秘密にはできない。完全に隠すなら診断ロジックのサーバー側移管が必要。


■ やったこと

- Tinder風の左右スワイプ、PCボタン/キーボード操作、進捗表示、回答時間保存を実装。
- 6軸スコア計算と、上位2軸から15タイプに分類する診断ロジックを実装。
- 診断結果マスタPDFを元に15タイプ分の初期データを反映。
- 管理画面を実装。
- 表示数値、診断結果文章、スワイプ画像/質問内容を管理画面で編集可能にした。
- スワイプ画像はドラッグ&ドロップでアップロード可能。ブラウザ側でWebP軽量化してSupabase Storageへ保存。
- 画像本体はDBに保存せず、URLとStorage内パスのみ保存。
- スワイプカードごとに出題ON/OFFを選べるようにした。
- 管理画面で新規質問を追加できるようにした。
- 管理画面で選択中の質問を削除できるようにした。DB行とSupabase Storage内画像も削除対象。
- 初期質問を100問に増やした。
- 出題ONの質問を候補プールにして、管理画面で設定した質問数だけ軸バランスを見てランダム出題するようにした。
- DBが40問までしか持っていない場合も、image-041以降の初期質問はdata.jsから補完される。管理画面で全データ保存するとDBにも入る。
- ルール説明画面を削除し、TOPの診断スタートから直接スワイプ開始に変更。
- 分析中画面を進捗バー + %表示に変更。98%で一瞬止める演出を追加。
- 分析完了後は自動遷移せず「診断結果を見る」ボタンで結果画面へ進むように変更。
- 診断結果と求人導線を1ページにまとめ、LINE CTAを目立たせた。
- Supabase DBと連携。
- diagnoses に answers / scores / score_rates / result_type を保存。
- analytics_events / diagnosis_events にKPI用イベントを保存。
- KPIを管理画面で日別 / 週別 / 月別に確認できるようにした。
- 管理操作ログの直近50件を管理画面で確認できるようにした。
- 離脱設問集計を実装。進捗を1行上書き保存し、30分以上停止で離脱として集計。
- 期限切れデータを毎日04:17 JSTに自動削除するCronを追加。
- LINE Login / Messaging API連携を実装。
- 2回目以降はLINE再ログインなしで診断結果を送信できるようにした。
- 利用規約 / プライバシーポリシーの仮ページを作成。
- LINE登録前に個人情報の扱いが分かる導線を設置。
- GA4タグを公開ページのheadに直接追加。診断タイプや回答内容は送らず、主要イベント名だけ送信。
- 管理画面ログインを追加。ADMIN_LOGIN_PASSWORDでログインし、8時間有効の管理セッションでadmin-ui / admin-master / kpi-summaryを呼び出す。
- 管理画面のログイン失敗回数制限、管理操作ログ、noindexを追加。
