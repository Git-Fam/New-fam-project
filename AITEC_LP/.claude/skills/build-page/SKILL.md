# ページ制作

- 対象ページと類似ページを先に確認する。
- ヘッダー、フッター、パンくず、見出し、ボタンなどは既存部品を再利用する。
- ページ固有SCSSは既存の `sass/page` のルールへ合わせる。
- SCSSは `pmin()` を `@include pc {}`、`s()` を `@include sp {}` で囲む。PC値をそのままSPへコピーしない。
- meta情報、リンク先、文言を推測しない。
- 共通部品の変更が必要な場合は影響ページを調査する。
- 指示されたページ以外は変更しない。
- PC・SP・中間幅とリンク、JSエラーを確認する。
