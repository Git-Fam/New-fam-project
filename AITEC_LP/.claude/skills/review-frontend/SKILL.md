# フロントエンドレビュー

変更はせず、まず問題を重要度順に報告する。修正指示がある場合だけ編集する。

確認項目：

- HTML構造、見出し階層、リンクとbuttonの使い分け、alt
- 横スクロール、文字切れ、重なり、PC・SP・中間幅
- JavaScriptエラー、対象要素なし時のエラー、多重イベント
- キーボード操作、aria属性、フォーカス
- 未使用・重複スタイル、過度な詳細度、不要な `!important`
- `pmin()` が `@include pc {}` 外にないか、`s()` が `@include sp {}` 外にないか
- PC値をそのまま `s()` へコピーしていないか（SPはFigmaのSP値か）
- WordPressのエスケープ、空値、ループリセット、入力検証
- Figmaとの差異、画像・フォント・リンクの不足

各指摘には対象ファイル、該当箇所、影響、推奨修正を含める。
