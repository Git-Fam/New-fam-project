# LP05「迷い」設計案(案A「迷いのチャット」・本実装)

結論(先頭3行)
- モック `mock-A-chat.html` を土台に、LP04 の色・書体・計測・SEO を揃えて `05mayoi/index.html` に実装します。3D は使わず、CSS だけの静的 iPhone で軽く仕上げます。
- 返事は「迷いごとに2通り」。初回は1通り目、「もう一度」後は2通り目。断定・保証はしません。
- 先にユーザー確認が必要な点が6つあります(末尾)。

---

## 1. この画面の1つの仕事(Purpose)
「迷っている人」が、迷いを否定されずに話を聞いてもらえた気持ちで、「まず写真から」のはじめの一歩(診断)へ進めること。
覚えてもらう1つのもの(署名要素)＝**自分の迷いが吹き出しになり、返事が返ってくるチャット**。他は全部、静かに支える。

## 3. 色・書体(LP04に合わせる)
- 壁色: ピンク #E9A9CF／青 #A4B3EC／紫 #D2AEEA(画像は 04mikeiken の wall-*.webp、上に白 50% を重ねて淡くする)。ライトモードのみ(`color-scheme:light`)。
- 文字色: ink #15131F、補助 #55536A(白地で 7.3:1)、リンク #5B35D5、アクセント #C93C94(装飾のみ・文字は使わない。白地で #C93C94 は 4.6:1 でぎりぎりのため)。
- 書体: **LP04と同じ**。見出し・吹き出し・ボタン＝Zen Maru Gothic 900/700、本文＝BIZ UDPGothic 400/700。モックの Dela Gothic One は廃止。
- 大きさ: 本文 17px(1.0625rem)、吹き出し 16.5px、補助 14px 以上(11px 未満なし)。見出しは clamp()。ボタン高さ 52px(最小44px)。
- 吹き出し: しごピタ＝白、自分＝ink(濃紺)。色だけで区別せず、左右位置＋アバター「ピ」でも区別。
- 小物: props-star/confetti/footprint を FAQ・メンター帯に少量(LP04と同じ配置の考え方)。1セクション2点まで。

## 4. チャットの設計

### 4-1 返事の文(迷いごとに2通り。やさしく・短く・断定と保証なし)
開始:自分「なんか、ずっと迷ってる。」→ しごピタ「そのままで、だいじょうぶ。」(小さく)「どんな迷いか、教えてください。」

| 迷いボタン(=自分の吹き出し) | 返事 1通り目 | 返事 2通り目 |
|---|---|---|
| やりたいことがわからない(「やりたいこと、わからない。」) | 「わからなくて、いいんです。」「考えるより、見て気づくこともあります。」 | 「それ、よくあることです。」「仕事の名前を、まだ知らないだけかもしれません。」 |
| いまの仕事でいいのか不安(「いまの仕事で、いいのかな…。」) | 「ちゃんと向き合っているから、不安にもなりますよね。」「答えは、急がなくて大丈夫です。」 | 「変えても、変えなくても。決めるのは、あとでいいんです。」「まずは、気になる場面を知るところから。」 |
| 向いてる仕事なんてあるの?(「向いてる仕事なんて、あるの？」) | 「あるとは言い切れません。でも、気になる場面なら見つけられます。」 | 「仕事の名前より先に、どんな場面が気になるかを見てみませんか。」 |
| 未経験だから自信がない(「未経験だから、自信がなくて。」) | 「経験を書く欄は、ありません。」「気になる写真を、選ぶだけです。」 | 「最初は、だれでも未経験です。」「まずは、気になるかどうかだけ。」 |

最初の1つを選んだ後だけ、締めの一言:「じゃあ、写真から見てみましょう。」→ CTAカードがふわっと出る。2つ目以降は返事のみ(重複させない)。
禁止の確認: 数字は 40枚/約2分/16タイプ/無料 のみ。「見つかります」「向いています」など保証表現なし(「あるとは言い切れません」で誠実に)。

### 4-2 動き・間(気持ちよさ)
- 入力中の点: 600ms ＋ 文字数×28ms(上限1400ms)。点は3つ、ゆっくり波打つ。
- 吹き出し: 下から 8px＋フェード 280ms。返事と返事の間 250ms。自分の吹き出しは即表示→450ms 後に点が出る(「聞いてくれている間」)。
- スクロール: 新しい吹き出しの下端を画面の下から 25% の位置に合わせる(`scroll-margin-bottom`＋`scrollIntoView({block:'end'})`)。選択ボタンは常に吹き出しの下に続き、押しても位置が跳ねない。ユーザーが手で上にスクロールした時は、自動スクロールを止める(押し戻さない)。
- 壁色: 選んだ迷いで 0.9s かけてピンク→青→紫(同じ迷いグループ内で順繰り)。`prefers-reduced-motion` では瞬時に切り替え。
- **戻る/やり直し**: 選んだボタンはチップから消えて自分の吹き出しになる(クイックリプライ方式)。残りのボタンで続けられ、4つ全部選んだらボタン欄は「ほかに迷いはありますか?→なければ、写真から。」だけになる。「もう一度、話してみる」で最初から(2通り目の返事に切替)。

### 4-3 競合状態・不具合対策(モックの返事混在を含む)
1. 返事の再生中は、全ボタンを `disabled`(押せないことが見た目と読み上げ両方に伝わる)。終わったら残りを有効化。
2. 再生は「世代トークン」方式: リセットや再開のたびに `gen++`。非同期の各ステップで `if(token!==gen) return` し、古い返事が新しい会話に混ざらない。
3. リセット中に返事が走っていても安全(トークンで打ち切り→DOMを全消去)。リセット自体も再生中は押せない/押したらトークンで割り込み。
4. 開始トリガの二重起動防止(IntersectionObserver と 2.5s フォールバックの二重 → `started` フラグ＋リセットとは独立)。
5. 入力中の点を `remove` するのは自分の世代のときだけ。
6. 追従ボタンの表示判定はスクロール停止後に rAF で一回(スクロール連打で重くしない)。

### 4-4 アクセシビリティ
- チャット領域: `role="log" aria-live="polite" aria-relevant="additions"`。**完成した吹き出しだけ**を追加する(入力中の点は `aria-hidden`、「入力中」の文字は視覚的に隠した別の短い通知にはしない=うるさいため)。
- 選択は `<button type="button">`。Tab で順に移動、Enter/Space で選択。選択後はフォーカスを「次に押せるボタン」へ戻す(消えたボタンにフォーカスが取り残されない)。全部選んだらフォーカスを CTA カードの見出しへ。
- フォーカスリング: LP04と同じ(黒3px＋白6px)。
- `prefers-reduced-motion`: 点・浮遊・スムーズスクロール・フェード全部なし。吹き出しは即表示、返事の待ち時間も 0(順番だけ守る)。
- スマホ幅375: 吹き出し幅 80%、ボタンは 1 列でも 2 列でも折り返し、タップ領域 52px 以上。

### 4-5 JSなし/軽量のとき(静的版)
HTML に4つの迷い＋返事(1通り目)を、`<ol>` の読み物として最初から全部書いておく(検索エンジンにも読める)。JS が動いた時だけ `html.js` で隠し、チャットが引き継ぐ。つまり JS なしでも「迷い→返事→CTA」が成立する。

## 5. 計測・個人情報
- GTM `GTM-TS9BKBR3`、Clarity(LP04と同じID)。`a[data-cta]` クリックで `dataLayer.push({event:'lp05_cta_click', cta_position})`。位置: header / iphone / final / closing / fab / footer / mentor 無し。
- CTA は `https://shigopita.jp/?utm_source=lp05&utm_content=<位置>`。
- 選択は保存・送信しない(メモリ内のみ。localStorage/Cookie/フォームなし)。Clarity には `data-clarity-mask="True"` をチャット領域に付けて、画面再生で吹き出しの中身が記録されないようにする。FAQ に「このページで選んだ内容は保存されますか?→保存・送信されません」を LP04 と同じ書き方で入れる。

## 6. SEO・構造化データ
- title 案: 「迷っていても、まず写真から｜無料の仕事診断｜しごピタ」
- description 案: 「やりたいことがわからない、いまの仕事で合っているか不安。そんな迷いのまま始められる、40枚の画像をスワイプする無料の仕事診断「しごピタ」(約2分・全16タイプ)。診断のあと、公式LINEから無料で転職の相談もできます。」
- canonical/OGP: `https://mayoi.shigopita.jp/`(仮・確認事項1)。OGP画像は LP04 と同じ `https://shigopita.jp/assets/ogp.png`。
- JSON-LD: Organization/WebSite/WebPage/BreadcrumbList(しごピタ>迷っている方へ)/FAQPage。FAQ は画面と同文。h1 は1つ。画像は全て WebP、width/height 指定、lazy。
- FAQ 6問: ①迷ったままでも使えますか ②本当に無料ですか ③どのくらい時間がかかりますか ④診断結果で仕事は決まりますか(LP04と同文) ⑤このページで選んだ内容は保存されますか ⑥診断のあと、相談はできますか。
- robots.txt、sitemap.xml(lastmod 2026-11-18)を 05mayoi に置く。

## 7. 素材
- **app-screen.webp には「4,503 人が診断済み」が入っている**(下部)。数字を使わない方針なので、下 128px を切り落とした `assets/app-screen-top.webp`(720×1112)を作成済み。切り落としたのは人数表記と「利用規約/プライバシー」リンクのみ。
- ただし切り抜き後の画面内にも、アプリ自体の文言「AIがあなたの適職を分析」「診断スタート(約2分)」が残る。これはアプリの実画面なので LP04 と同様に使うが、「適職を分析」が断定の誤解を招かないかは確認事項2。
- ロゴ(logo.webp)は白背景付き → 白いヘッダー上にだけ置く(`mix-blend-mode:multiply` はやめ、白地に載せる)。
- 写真は q/q01〜q03 から3枚を CTA カードに(質問用の情景写真)。ほかは card-* と props-*、wall-*。
- 新しい素材は**今のところ不要**(Codex への指示書は書かない)。

## 8. 3D は使うか
**使わない。** 理由: この LP の主役は会話であり、動く3Dは吹き出しの動きと競合する。CSS の iPhone(角丸・ノッチ・影)で十分に「これが、しごピタ」を伝えられ、軽い。LP04 の3D を足すのは、後から「PCだけ」で追加できる構造にしておく(iPhone 部分を1つのコンポーネントにまとめる)。
