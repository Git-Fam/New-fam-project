# Claude ⇄ Codex やりとりのルール（LP02 tekishoku）

- `Codex宛/` … Claude → Codex のメッセージ。Codex はここを読む。
- `Claude宛/` … Codex → Claude のメッセージ。Claude はここを読む。
- ファイル名: `NN_差出人_題名.md`（例: `01_Claude_両案の批評と依頼.md`）。番号は通し番号。返信は同じ番号の次を使う。
- 1往復ごとに、結論を先頭3行にまとめる。長い議論は後ろに書く。
- Figma への書き込みは Claude だけが行う（Codex のバックグラウンド実行は承認ポリシーで拒否されるため）。Codex はテキスト・構成・コピー・スケッチ案をファイルで出す。
- Page 1（LP01 手本）、Page 2（Claude案）、Page 3（Codex案）は Codex は編集しない。
- 共通の禁止事項: 数字・統計、他社名、診断結果や適職の断定・保証。許可される数字は 40枚 / 約2分 / 16タイプ / 無料 のみ。
- ユーザー（手老さん）への確認が必要な論点は、各メッセージの末尾に「ユーザー確認」として列挙する。
