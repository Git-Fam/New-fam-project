# LP04「未経験」設計案(v2: ずっとiPhone)

結論: 主役は最初から最後まで3DのiPhone。山場は「iPhoneがくるっと一回転して(背面のしごピタロゴが見える)、前を向いたところで画面がぱっと点き、近づいてくる」。缶は使わない。

## 0. 考え方
- 一言で: 未経験の人が「何から始めれば…」で止まらないよう、診断(40枚・約2分・無料)という小さな入口を見せるページ。
- 山場は1つだけ: 5の「まわって、画面が点く」。ほかの演出(壁色の切替・カードが流れる)は静かにする。
- 約束しないこと: 「未経験でも必ず」「おすすめ業界」「求人」。

## 2. 3Dの作り
Three.js r186(importmap)/ GSAP 3.13 ScrollTrigger。iPhoneは押し出し形状の角丸の枠+画面(素材/IMG_1877)+ダイナミックアイランド+背面(白・ロゴ・カメラの出っぱり)。画面は MeshBasicMaterial で、色の係数だけ暗転→点灯させる。カメラは道を奥へ進み、iPhoneはカメラについてくる。

## 3. 静止版
JSなし / WebGL不可 / reduced-motion / 低性能 / ユーザーが「3Dをとばして静止版で見る」を押したとき。同じ文章・順序で、iPhoneはCSSの枠(少し傾けて見せる)。
