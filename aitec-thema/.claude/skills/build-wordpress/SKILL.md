# WordPress実装

1. テーマ構成、`functions.php`、inc構成、プラグイン、対象テンプレートを確認する。
2. 既存設計がなければWordPress標準のテンプレート階層に従う。
3. ACFのフィールド名と返り値形式は定義を確認し、推測しない。
4. 値が空の場合に不要なマークアップを出さない。
5. URL・属性・テキストを用途に応じてエスケープする。
6. `query_posts()` は使わず、独自ループ後は `wp_reset_postdata()` を行う。
7. 投稿タイプやタクソノミー登録は既存の分割方式へ合わせる。
8. フォームは使用プラグイン、確認画面、バリデーション、文言を確認する。
9. プラグイン追加や管理画面仕様変更は明示的な指示がある場合だけ行う。
10. 変更テンプレート、管理画面側の必要設定、未確認事項を報告する。
