# LP制作

- Figmaのセクション単位で独立性のある構造にする。
- CTAの文言、リンク先、表示条件を推測しない。
- FVを無条件に `100vh` にせず、モバイルブラウザの高さ変動を考慮する。
- 重要テキストは可能な限りHTMLにする。
- absolute配置を多用せず、flex/gridを優先する。
- 固定CTAが本文やフォームを隠さないか確認する。
- アニメーションは操作とコンバージョンを妨げないようにする。
- `prefers-reduced-motion` を考慮する。
- FV画像と下部画像で読み込み方を分け、表示速度を意識する。
